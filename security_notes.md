## Notes

- The program moves the real system cursor, so do not enable it while precise mouse work is in progress.
- The movement interval is 30 seconds in this sample.
- The display-awake request is released when Turn Off is clicked or when the dialog closes.
- This program does not bypass Windows security policies and does not disable password/PIN protection.
- If the computer is managed by an organization, policy may override power or sign-in behavior.
